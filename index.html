How it works

  1. 1

    Choose apps

    Pick launchable apps on the device. Each one has its own rule. Nothing is turned on for you.

  2. 2

    Write the pause

    The default notice is “What brought you here?” Quit leaves. Anyways continues. Renaming a button does not change what it does.

  3. 3

    Set a reminder

    Never, 5, 10, 15, 20 minutes, or a custom interval. Never still shows the opening pause.

  4. 4

    Use the app on purpose

    After Anyways, a later check-in can ask “You're still here?” Wait snoozes. Dismiss stops reminders for that app until tomorrow. The rule stays enabled.

What is in the app

These are implemented in the native project. The pause over another app has not been demonstrated on a physical phone in this workspace.

  • Independent rules

    Opening notice, button labels, reminder copy, and snooze are stored per app, on the device.

  • System, Light, and Dark

    System is the default. A theme change applies without restarting the app.

  • A pause, not a lock

    Quit sends you home. It does not force-stop the other app. Anyways lets that app continue.

  • Monitoring you can stop

    Settings can pause monitoring without deleting rules. Declining a permission leaves Momentwise as a configuration app.

Permissions

Momentwise asks only when you enable a rule, and explains each grant before the system screen.

Usage Access
Needed to notice which app is in front. It is a Settings grant, not a normal dialog. Momentwise does not turn that into a usage chart.
Notifications
The monitor runs as a foreground service, so Android requires a persistent notification. If display-over-other-apps is off, the pause itself is a notification you tap.
Display over other apps
Optional. When allowed, the pause is Momentwise’s own screen over the other app. It is not an invisible window held open for a privilege. You can skip it.

There is no Momentwise account, analytics SDK, or advertising SDK in the app. Rules stay in on-device storage. There is no Momentwise server receiving them. Android, GitHub, and this website have their own logs; that is not the same as the app uploading your rules.

Install

The proposed application ID is com.nawzblaze.momentwise. The app is not published on Google Play.

A stable signing key is not stored in this repository, and the release workflow will not upload an APK until these GitHub Actions secrets exist:

  • MOMENTWISE_KEYSTORE_BASE64
  • MOMENTWISE_KEYSTORE_PASSWORD
  • MOMENTWISE_KEY_ALIAS
  • MOMENTWISE_KEY_PASSWORD

When a signed file is published, the download should be https://github.com/NawzBlaze/momentwise/releases/latest/download/Momentwise.apk. That URL is not linked here, because the file is not there. Sideloading an APK always needs your approval in Android settings. Install only a build whose signature and checksum you can check.

A debug build can be produced from the repository with JDK 17 and Android SDK 35. See the Android readme in the source tree. A debug APK is not the public release.

Questions

Does Quit close the other app for good?

No. Quit returns you to the launcher. Android does not let a normal app force-stop another app, and Momentwise does not try.

Are reminders exact to the second?

No. The monitor polls usage events about once a second while it is allowed to run. A reminder is due after the interval you set, then shown on the next poll. Doze, a revoked permission, or a paused monitor can delay or stop that. It does not use exact alarms.

What if I dismiss a reminder?

Reminders for that app stop until the next local day. Other apps are unchanged. The rule stays enabled.

Which Android versions?

The project targets API 35 and can install from API 26. The pause path has not been verified here on an API 34 or API 35 device. Vendor battery limits can stop a foreground service. If a grant is missing, the app says so instead of pretending the pause will appear.

Where is the old prototype?

A browser design reference is still published at /prototype/ until a signed APK is available and this page can offer it. That reference is not the Android app, and it is not the product download.

Where do I report a problem?

Open an issue on GitHub. There is no separate support desk.
