How it works

Momentwise does not lock you out. It asks, then gets out of the way.

  1. 1

    Choose the apps

    Each app has its own prompt, buttons, and reminder. Nothing is turned on until you enable it.

  2. 2

    Pause when you open one

    A new rule asks what you want to do right now. Leave goes home. Continue stays. Closing the pause without choosing is not Continue.

  3. 3

    Reminders, if you want them

    A new rule starts at 5 minutes, after Continue. Never still shows the opening and does not schedule a reminder. The interval is not an exact alarm.

  4. 4

    Stop whenever you want

    Settings can pause monitoring without deleting rules. Declining a permission leaves Momentwise as a configuration app.

Permissions

Momentwise explains each grant before the system screen, and only asks when you enable a rule.

Usage Access
Needed to notice which app is in front. It is a Settings grant, not a normal dialog. Momentwise does not turn it into a usage chart.
Notifications
Android requires an ongoing notification while the monitor is running. It reads “Momentwise is on.” If the pause cannot cover the other app, a separate notification asks you to open it. That notification does not block the app.
Display over other apps
Optional. When allowed, a card covers about the middle of the screen and the other app stays visible behind a scrim. Touches do not pass through. You can skip it.

Rules stay on the device. There is no Momentwise account. The app does not include an advertising or analytics SDK. Android and GitHub have their own logs.

Download

Momentwise is not on Google Play. A signed Android download is not published yet, so the button above stays off.

The source is public. Build and signing notes live in the repository, not on this page. A debug build is not the release.

Leave does not force-stop the other app. A phone battery manager can stop monitoring. The pause can be about a second late, and some phones delay it further. That has not been measured as a battery percentage.
